# Store screenshots

Screenshots for the store listings, captured from the running apps.

| Store                         | Size                         | Folder     |
| ----------------------------- | ---------------------------- | ---------- |
| Chrome Web Store, Edge, Opera | 1280×800 PNG, up to 5        | `browser/` |
| Firefox Add-ons               | 1280×800 PNG                 | `browser/` |
| Google Play                   | Phone, 1080×1920 PNG, 2 to 8 | `android/` |

Name files by order and subject, for example `browser/1-combined.png`. The store
listing texts live next to the code: `multiwarden/store/listing.md` in
[multiwarden/clients](https://github.com/multiwarden/clients).
